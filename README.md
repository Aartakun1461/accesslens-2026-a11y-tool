## 🛠 Features

AccessLens provides a set of tools to improve your design workflow.

- **Automated Scanning:** The software scans your design files for common accessibility mistakes.
- **Detailed Reports:** You receive a report that lists errors and explains how to fix them.
- **WCAG Compliance:** The tool benchmarks your work against the official WCAG 2.1 AA standards.
- **Early Detection:** Identify issues before writing code to prevent costly rework.
- **Browser Integration:** Use the tool directly within your design workflow.

## 💡 Best Practices

Follow these tips to get the most out of your accessibility checks:

*   **Test Early:** Run a scan as soon as you have a rough layout.
*   **Test Often:** Run a check every time you update your colors, contrast, or text placement.
*   **Fix One Item at a Time:** Address color contrast issues first, as these are easy to correct.
*   **Document Success:** Export your final report to show that your design meets accessibility requirements.
